# SSH-App (iOS + Rust Core)

Native iOS mobile application (SwiftUI + Rust Core via UniFFI) for securely managing remote terminal sessions and AI agents (Claude Code, Google Antigravity, Ollama/local models) on MacBook over Tailscale.

## Key Technical Requirements & Constraints

1. **Zero Battery Drain**:
   - iOS background mode: when minimized (`sceneDidEnterBackground`), the TCP socket is immediately closed.
   - 0% CPU & radio usage in background.
   - Remote host persists long-running agent tasks inside `tmux`.
   - On foreground (`didBecomeActive`), the Rust core instantly reconnects and re-attaches to the tmux session.

2. **Universal Host Environment & tmux**:
   - Dynamic `$SHELL` detection (never hardcode shell paths).
   - Login shell execution (`zsh -l -c ...`) ensuring `~/.zshrc`, PATH, and agent keys are loaded.
   - TrueColor support (`terminal-overrides ",xterm-256color:Tc"`).
   - Strict argument quoting / parameterization to prevent command injection.

3. **Multi-Session Isolation**:
   - Multiple tabs (e.g. Claude Code, Antigravity, Local LLM).
   - Each tab maps to an isolated tmux session.
   - Dynamic PTY resizing: viewport geometry changes trigger `window_change` -> remote `SIGWINCH`.

4. **Security & Cryptography**:
   - Ed25519 keypair generated by Rust (`ssh-key` + CSPRNG).
   - iOS Keychain storage with `kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly`.
   - Sensitive memory zeroized on drop (`zeroize`).
   - Host key verification to prevent MITM.

## Development Workflow

We follow the dev-chain workflow:
```
doc-dev → rev → rust-core-dev → rev → swift-bridge-dev → rev → ios-ui-dev → rev → hacker → merge
```

Always ensure:
- Rust code passes `cargo fmt`, `cargo clippy -D warnings`, and `cargo test`.
- UniFFI interface is clean, safe, and returns typed errors (no `unwrap()` in public paths).
- Swift code maintains clean concurrency (actors/async-await) and no UI freezes.
