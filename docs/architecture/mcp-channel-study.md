# MCP как канал агент → телефон (изучение, 2026-10-21)

Вопрос: что нам даёт MCP и годится ли он для чата. Коротко: **для извлечения чата - нет, как канал от агента к
телефону - да** (вариант K к `chat-extraction-alternatives.md`).

## 1. Что такое MCP здесь

Агент (Claude Code, agy) - клиент MCP. Сервер выставляет ему инструменты, ресурсы, промпты. Направление
«агент зовёт нас»: разговор агента через MCP не читается, зато агент может сам отправить нам данные или задать вопрос.

## 2. Проверено на этой машине (`--help`, конфиги; ничего не менялось)

| Факт | Откуда |
|---|---|
| Claude Code 2.1.303: `claude mcp add\|add-json\|get\|list\|remove\|login\|serve\|reset-project-choices`; транспорты `stdio`, `sse`, `http`; области `local`, `user`, `project` | `claude mcp --help`, `claude mcp add --help` |
| `claude --mcp-config <файлы>` и `--strict-mcp-config` подключают серверы на один запуск, не трогая общую конфигурацию | `claude --help` |
| Серверы из `.mcp.json` проекта требуют одобрения («Pending approval»); хранятся в `~/.claude.json` (`mcpServers`) | `claude mcp list`, `~/.claude.json` |
| agy 1.4.4: `agy mcp add\|remove\|list\|enable\|disable`; `stdio` и `http`; флаги `-e`, `-H`, до имени | `agy mcp --help`, `agy mcp add --help` |
| agy хранит серверы в `~/.gemini/config/mcp_config.json` (сейчас пустой файл) и в `plugins/<имя>/mcp_config.json` (формат `{"mcpServers": {имя: {command, args, env}}}`, например flutter) | файлы в `~/.gemini/config` |
| Вызовы MCP-инструментов видны в журнале Claude как `mcp__<сервер>__<инструмент>` (так же, как это уже учитывает парсер экрана) | журналы сеансов |

## 3. Не проверено (нужен живой запуск модели)

- Обязательно ли агент вызовет наш инструмент, и как в TUI выглядит вызов (карточка, запрос разрешения на сам вызов).
- Как agy обрабатывает долгий вызов (ждать ответа телефона минуты) и есть ли таймаут инструмента.
- Поддерживают ли агенты запрос ввода у пользователя со стороны сервера (elicitation) - в `--help` не упомянуто.
- Нужна ли подтверждающая карточка на каждый первый вызов нашего сервера (разрешение `mcp__ssh-app__*`).

Проверка безопасная: временный конфиг через `--mcp-config` + `--strict-mcp-config`, сервер на stdio в песочнице
(`~/.ssh-app` не трогать), один короткий `claude -p`. Это вызов модели на аккаунте владельца - делать по его слову.

## 4. Что из этого следует

1. **Извлечение чата**: MCP не даёт. Список A–J не меняется.
2. **`--permission-prompt-tool` не заменяет наши хуки**: он работает только в `--print`, а наши сеансы - интерактивный
   TUI в tmux. Подписанные одобрения через хуки остаются единственным путём для TUI.
3. **Вариант K - сервер `ssh-app` для агента** (режим `ssh-app-host mcp`, stdio, без сети и без слушающего порта,
   как и хуки). Инструменты, по убыванию пользы:
   - `ask_phone(question, options[])` - структурный вопрос вместо разбора меню с экрана; ответ приходит
     результатом вызова. Использует ту же очередь `~/.ssh-app/run`, что и одобрения.
   - `notify_phone(text)` - точный текст о завершении (вместо догадок по Stop-хуку).
   - `show_artifact(kind, data)` - диаграмма, дифф, таблица как данные (M30).
   - `report_progress(step, total, label)` - для Live Activities (M28).
   - `get_attachment()` - путь загруженного с телефона файла (M27).
4. **Ограничения K**: агент вызывает инструмент по своей воле или по подсказке в промпте (хуки это гарантируют, MCP
   нет); всё, что пришло от агента, недоверенный ввод (как pane и transcript); ответы телефона - данные, не команды;
   регистрация в двух форматах (`claude mcp add-json`/`--mcp-config` и `mcp_config.json` agy) - расширение
   установщика хуков; для Claude серверы проекта требуют одобрения, поэтому регистрировать надо в области `user`
   конфигурации профиля (`CLAUDE_CONFIG_DIR`).

## 5. Предлагаемый порядок

1. Живая проверка из §3 (по слову владельца) - один вечер, результат в этот документ.
2. Спека «MCP-канал ssh-app» (`ask_phone` + `notify_phone` как v1), безопасность по правилам хуков: очередь,
   подпись решения телефона, длина и вид полей, display-safe текст.
3. Реализация в `crates/host` (`mcp` как подкоманда helper) + установщик в `agent_hooks` + карточка в приложении.
