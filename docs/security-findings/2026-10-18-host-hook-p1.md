# Security pass: host hook in Rust (P1, feature 25), 2026-10-18

## 1. Scope

`crates/host/src/{queue,guard,hook,ctl,sessions,statusline,pyjson,proc}.rs`, the shim in
`scripts/agent-hooks/ssh-app-hook.py` (`exec_helper`), `agent_hook_script()` pinning. Reference and
oracle: the Python implementation.

Live (own temp `SSH_APP_HOME`, release helper, no network, no tmux): 100 MB stdin without newline,
100 000-level nested JSON, 32 KB command full of quotes/wrappers under deny rules, 30 KB of `a`
against a catastrophic-looking glob rule, FIFOs / symlinks / flood in the queue (hook suite on the
Rust implementation), forged/stale/misdirected decisions (same suite), differential fuzz of the
guard against Python (4000 generated calls), shim with wrong pin / replaced / group-writable /
symlinked / absent helper. Ruled out: crypto implementation (verification is `ssh-keygen -Y verify`,
unchanged), network surface (none).

## 2. Findings

1. **Fail-open on oversized payload** [InputValidation, Medium] — `hook.rs`. A hook payload beyond
   the read cap (32 MiB) was treated as `{}`, so the phone was asked to approve a blank request that
   stands for the real tool call. Live: 100 MB stdin. **Fixed**: such a payload is denied outright
   (`permission()`), test `a_payload_beyond_the_read_cap_is_refused_not_sent_to_the_phone_blank`.
2. **Hash-then-exec window in the shim** [SandboxEscape, Low, accepted] — the digest is checked on
   one open file, then the path is executed; a same-user process can swap the file in between. That
   attacker already runs as the user (same as 24 section 3); the check protects against stale or
   accidentally replaced helpers. Direction if ever needed: exec from the verified descriptor.
3. **Blank approval on garbage payload** [InputValidation, Low, pre-existing, same in Python] — an
   agent sending unparsable JSON for a permission event yields a request with empty fields. The
   agent is not an attacker here; left for parity.

No finding: resource use (38 MB RSS at the 32 MiB cap, 4-5 MB otherwise, deadlines honoured),
regex backtracking (Rust `regex` is linear), shlex input (capped at 32 KB before splitting),
decision forgery (the whole forged/stale/misdirected/flood suite passes on Rust), FIFO/symlink in the
queue (`O_NOFOLLOW|O_NONBLOCK`, regular-file and owner checks), guard bypass (differential fuzz: no
disagreement with the Python reference).

## 3. Verdict

Findings (highest severity Medium), the Medium one fixed.
